# 0.8.0 adversarial review follow-up

This records the disposition of the [independent review of PR #64](https://github.com/war-and-code/dircue/pull/64#pullrequestreview-5270240201). Finding identifiers below retain the review's section-local numbering. Fixes, deliberate compatibility boundaries, and future capability work are distinguished. The PR remains subject to review; this document is not release authorization or a general correctness certification.

## Verification

The post-review candidate was built from clean commit `11a04cab3700f4f98162874144b500ad5a7041bb` with Go 1.26.6 for darwin-arm64. Candidate SHA-256: `0d85c9beb82a46791d24a1b2d87bc1f46dc8d6e98395434aed1399180f524fd9`. The build manifest records 361 Go compilation inputs; subsequent documentation/evidence changes leave those inputs unchanged.

- **278/278 inherited** and **18/18 targeted** cases match released 0.7.0 stdout, stderr, and exit status exactly.
- **426 Linguist cases:** 408 passes, 18 documented expected differences, zero unexpected failures. Two expected differences verify terminal-path escaping against a narrowly defined oracle; language JSON remains exact.
- **13 packaged context checks**, **six scc conformance checks**, and **21 native structural fixtures covering 20 languages** pass.
- `go vet ./...` and `go test -race ./...` pass. Packaging tests pass (73 tests, two designed skips), along with 13 CI tests and five context-receipt tests.
- Strict receipt-integrity verification passes: binary identities, clean build source/commit/tree, current compilation inputs, stored raw compatibility outputs, and all ten recorded performance lanes agree. It does not replay scans or attest that a record is authentic execution.

Local advisory checks found no reachable Go vulnerabilities or Rust advisories requiring action. These database-dependent checks also run in CI. Cross-platform results for the final PR head are tracked in [PR #64](https://github.com/war-and-code/dircue/pull/64); macOS-local receipts do not substitute for those results.

# dircue Parity Atlas

This directory contains the harness for the dircue parity and accuracy atlas:
a differential runner that compares dircue against Linguist 9.7.0 and scc 4.1.0
on a corpus of pinned public repositories.

### Corpus size note

`corpus.json` contains 38 repos rather than the ~50 mentioned in issue #107.
The 38 repos were chosen to cover the key ecosystem axes:
multi-language monorepo (linux kernel), multi-service app (microservices-demo, eshop),
Terraform infra (terraform-aws-vpc, terraform-alias, terraform),
Helm chart repo (helm-examples), Kubernetes (kubernetes),
Go (cobra, ripgrep, prometheus, traefik, oras, jq), Python (flask, django, uv,
functions-framework-python), JavaScript/TypeScript (express, react, typescript, pnpm, next,
actions-toolkit), Java/Kotlin (spring-framework, spring-petclinic, kotlin-koans),
.NET/C# (roslyn, aspnetcore, dotnet-samples, eshop), Ruby (rails, bioperl),
PHP (laravel), Perl (bioperl), Nix (nixpkgs), serverless (serverless-examples, aws-sam-java-rest)
and JVM build (apache-maven).
The remaining gap to ~50 would be covered by additional repos in the full BCA parity pass
tracked in issue #110.

## Structure

```
tests/atlas/
  corpus.json              Pinned corpus manifest (38 repos, commit SHAs, notes)
  fetch.py                 Fetch script: shallow-clones pinned commits into a cache dir
  run.py                   Differential runner (Linguist + scc)
  classify.py              Discrepancy classification logic
  accuracy.py              Accuracy card generator (precision/recall from hand labels)
  known-differences.json   Documented upstream differences (never silently excluded)
  test_classify.py         Python unit tests for classification logic
  test_accuracy.py         Python unit tests for accuracy card math
  README.md                This file
```

Generated outputs (not committed, attached as release assets):
```
.cache/atlas/
  atlas-results.jsonl      Correctness results (deterministic; timings excluded)
  atlas-timings.jsonl      Wall time and RSS per invocation (separate from correctness)
  atlas-summary.md         Human-readable summary with agreement rates
```

The accuracy cards are embedded in the binary:
```
internal/atlas/
  accuracy.go              Go package exposing embedded accuracy_data.json
  accuracy_data.json       Generated by make accuracy-cards; compiled into dircue
  accuracy_test.go         Go tests for the embedded data
docs/ACCURACY.md           Generated Markdown accuracy report
```

## Reproduction: one command per published number

### 1. Fetch corpus

```
make atlas-fetch
```

Or fetch the smoke subset only:

```
python3 tests/atlas/fetch.py --cache /tmp/atlas-cache --smoke
```

### 2. Run the smoke subset (5 repos, ~2 min)

```
make atlas-smoke
```

This installs scc 4.1.0 automatically. The Linguist comparison runs whenever the
`dircue-linguist:9.7.0` image exists locally (build it once with `make reference`);
without it, the smoke run reports the Linguist comparison as skipped. Results
appear in `.cache/atlas/`.

Linguist and dircue read the same input: the repository's committed `HEAD`
tree. The harness copies only the clone's `.git` directory into the container
(`--network none`) and runs `github-linguist` on it. It does not use `git
archive` (which applies `export-ignore` and `export-subst`) or re-commit files
(which applies `.gitignore`).

### 3. Run the full atlas (all 38 pinned repos)

```
make atlas
```

### 4. Generate accuracy cards

```
make accuracy-cards
```

This requires the labeled corpus repos to be in the cache (run `make atlas-fetch` first
for the map-corpus repos that have quality expectations). Writes `docs/ACCURACY.md`
and `internal/atlas/accuracy_data.json`.

### 5. Print embedded accuracy cards

```
dircue capabilities --accuracy
dircue capabilities --accuracy --json
```

## Corpus selection

The corpus (`corpus.json`) contains 38 repositories across ecosystems. The
`smoke_ids` field lists the 5-repo subset used in CI. Hard cases include:

- `linux`: Linux kernel — exercises C/Assembly/Kconfig/Makefile, strategy chain (#72 regression)
- `bioperl`: Perl-heavy repo (deliberately hard for Linguist)
- `nixpkgs`: NixOS nixpkgs (Nix-only at scale)
- `kubernetes`: Large Go monorepo with vendor/
- `pnpm`: pnpm workspace (deliberately hard for JS workspace detection)
- `roslyn`: C# + VB regression (#73)

## Discrepancy classification

Every discrepancy is classified as one of:
- `matched` — no discrepancy
- `dircue-bug` — dircue produces a different result not in the known-differences list
- `known-upstream-diff` — documented in `known-differences.json`
- `harness-issue` — harness produced unreliable oracle output

Nothing is silently excluded. The runner exits 1 on any uncategorized mismatch.

## CI

The `atlas.yml` workflow runs on `workflow_dispatch` (full or smoke) and on
review-ready pull requests that change the atlas or analysis code (smoke subset
only). Draft pull requests skip the Docker-backed corpus job.
There is no `schedule:` trigger. Results are uploaded as GitHub Actions artifacts
(7-day retention) and optionally attached to a release when `release_tag` is
supplied to `workflow_dispatch`.
